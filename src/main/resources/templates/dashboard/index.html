Guía rápida para recepción
Para registrar una nueva cita
  1. Solicitar DNI al paciente.
  2. Validar si el paciente existe.
  3. Registrar paciente si no existe.
  4. Elegir especialidad, médico y horario disponible.
  5. Confirmar la cita médica.
Para registrar ficha de admisión
  1. Solicitar DNI al paciente.
  2. Consultar la cita médica registrada.
  3. Validar que la cita corresponda.
  4. Crear la ficha de admisión.
  5. Derivar el flujo a enfermería.
